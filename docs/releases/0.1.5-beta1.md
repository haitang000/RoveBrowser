# Rove 0.1.5-beta1

这是 Rove 0.1.5 的首个预发行版本。

## 新增与改进

- 新增浏览历史页面，可按日期筛选、排序，并按站点或浏览会话查看。可从最近关闭列表恢复标签。
- `Ctrl+Tab` 打开可视标签切换器。标签悬停预览在缩略图就绪后展开，缩略图捕获也减少了重复工作。
- 侧栏新增 Now Playing 卡片，可为后台媒体标签播放、暂停或静音。卡片支持悬停展开，并根据媒体封面调整配色。
- 外观设置可调整侧栏密度。辅助功能设置新增默认页面缩放和文本朗读，可用快捷键朗读网页，也可通过右键菜单朗读选中文字。
- 隐私设置新增站点权限默认规则和 WebRTC 地址保护选项。
- Agent 本地接口增加可选的普通标签管理、网页快照、元素点击和文本框填写。实验性设置新增 Chrome DevTools MCP 接入。两个入口均需主动启用。
- 复用 WebView2 环境，减少重复初始化，并统一设置下拉菜单和右键菜单的样式。

## 下载

- 安装版 `Rove-0.1.5-beta1-windows-x64-setup.exe`
- 便携版 `Rove-0.1.5-beta1-windows-x64.zip`，解压后运行 `Rove.exe`
- `SHA256SUMS.txt` 提供两个文件的 SHA-256 校验值

支持 Windows 10/11 x64，以及能够运行 x64 应用的 Windows ARM64。需要 Microsoft Edge WebView2 Evergreen Runtime。安装版支持覆盖升级并保留用户资料。
