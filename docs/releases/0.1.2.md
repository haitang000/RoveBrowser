# Rove 0.1.2

修复普通浏览、网页跳转及连续刷新时偶发整窗未响应的问题，提供 Windows x64 安装程序与便携版。

## 修复内容

- 将标题栏拖拽改由 Windows 原生输入层处理，避免 WebView2 的 CSS 拖拽子窗口在网页跳转时阻塞主线程。
- 保留标题栏拖动、双击最大化与还原，导航按钮、地址栏和窗口按钮各自接收输入；窗口缩放、侧栏调宽与折叠后同步更新拖拽区域。
- 新增真实 WebView2 普通浏览回归，覆盖链接点击、SPA 路由和标题更新、标签开关、宿主响应及退出保存。

## 下载与升级

- **安装版**：下载 `Rove-0.1.2-windows-x64-setup.exe` 并运行，可覆盖安装升级。
- **便携版**：下载 `Rove-0.1.2-windows-x64.zip`，解压后运行 `Rove.exe`。
- `SHA256SUMS.txt` 提供两个文件的 SHA-256 校验值。

支持 Windows 10/11 x64，以及能够运行 x64 应用的 Windows ARM64；需要 Microsoft Edge WebView2 Evergreen Runtime。升级保留用户资料、会话与登录状态。

107 项前端单元测试、128 项 Rust 测试和 20 项窗口布局界面测试通过；真实 WebView2 完成 300 次链接跳转、30 次 SPA 更新、20 轮标签开关及 30 次连续刷新检查。部分既有综合回归仍有超时，具体范围及已知限制见[验证记录](https://github.com/haitang000/RoveBrowser/blob/v0.1.2/docs/VALIDATION.md)与[使用说明](https://github.com/haitang000/RoveBrowser/blob/v0.1.2/README.md)。
