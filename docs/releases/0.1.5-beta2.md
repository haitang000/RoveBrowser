# Rove 0.1.5-beta2

这是 Rove 0.1.5 的第二个预发行版本。

## 新增与改进

- **网站权限**改为总览和独立详情页。可分别设置位置、摄像头、麦克风、通知和屏幕共享的默认行为，并在详情页筛选、添加或修改允许和阻止的网站例外。
- **安全 DNS**加入隐私设置。当前 DNS 服务支持时，通过 HTTPS 加密 DNS 查询。关闭或无法使用时，浏览器使用系统 DNS。
- **Codex 标签页分享**可从浏览器菜单选择当前标签页，并在使用结束后停止分享。
- **导航反馈**增加地址栏加载动画，调整后退、前进和重新加载控件的动画。
- **Chrome DevTools MCP**默认关闭，可在实验性设置中启用。

## 下载

- 安装版 `Rove-0.1.5-beta2-windows-x64-setup.exe`
- 便携版 `Rove-0.1.5-beta2-windows-x64.zip`，解压后运行 `Rove.exe`
- `SHA256SUMS.txt` 提供两个文件的 SHA-256 校验值

支持 Windows 10/11 x64，以及能够运行 x64 应用的 Windows ARM64。需要 Microsoft Edge WebView2 Evergreen Runtime。安装版支持覆盖升级并保留用户资料。
