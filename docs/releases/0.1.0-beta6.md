# Rove 0.1.0-beta6

- 新增默认浏览器设置：安装版和便携版可注册 HTTP／HTTPS 候选项，在 Windows 设置中选择 Rove；显示实际默认状态，支持外部链接冷启动与单实例转交。
- 迁移 Zigzag 五步首次引导，支持步骤恢复、常用网站选择和设置页重新打开。
- 支持从 Edge、Chrome、Firefox、Brave、Vivaldi、Opera 导入书签及历史；密码支持 CSV 导入、Windows 账户加密和用户选择账号填充。
- 新增下载面板、进度、暂停／继续、取消及下载历史。
- 完善标签菜单、标签老化与 Clear／Undo；切换工作区恢复各自上次显示的标签，侧栏滚动条按需显示。
- 修复缓存图标被放大导致的模糊，并优先使用网站声明的清晰图标。

Windows 10/11 x64。安装版升级保留原有会话、书签和登录状态；便携版解压后运行 Rove.exe。缺少 WebView2 时，安装版会使用微软引导程序安装运行时。

默认浏览器须在 Windows 设置中最终选择；当前处理 HTTP／HTTPS 网页链接，未关联本地 HTML／PDF。密码导入使用原浏览器导出的 CSV。广告拦截后端尚未提供，安装包尚未代码签名。
