# Rove 0.1.3

Rove 0.1.3 正式版新增阅读模式和扩展支持，改进分屏操作，并加入应用内检查更新。

## 新增与改进

- **阅读模式**可提取文章正文并保留图片、代码和表格。点击地址栏阅读按钮或按 `Ctrl+Alt+R` 打开，可以调整字体、字号、栏宽和主题。
- **扩展**支持加载本地 Manifest V3 扩展，也支持通过 Chrome 网上应用店的详情链接或扩展 ID 安装公开扩展。安装前会显示权限供确认。
- **分屏**在侧栏以一组标签显示，两侧各有独立的导航和地址栏。将侧栏标签拖入网页区域即可分屏，分隔条支持调整比例和交换两侧。
- **网页工具**新增打印、另存为和按标签保存的缩放比例，支持 `Ctrl+滚轮` 缩放。网站请求摄像头、麦克风等权限时会显示确认提示。
- **应用内更新**可在「设置 → 关于 Rove」查看版本，选择 Preview 或 Canary 通道并检查更新。确认后 Rove 会下载并校验更新包，保存会话并重启。
- **新标签页**改用更紧凑的布局，并在组件库展示实时预览。

## 修复

- 切回 Rove 时恢复键盘焦点，修复网页视频全屏时未铺满屏幕的问题。
- 为 HTTP 导航错误显示内置错误页，恢复原生下载对话框和下载安全提示。

## 下载与升级

- **安装版**：运行 `Rove-0.1.3-windows-x64-setup.exe`，可覆盖安装升级。
- **便携版**：解压 `Rove-0.1.3-windows-x64.zip` 后运行 `Rove.exe`。
- `SHA256SUMS.txt` 提供两个文件的 SHA-256 校验值。

支持 Windows 10/11 x64 和能够运行 x64 应用的 Windows ARM64，需要 Microsoft Edge WebView2 Evergreen Runtime。覆盖升级保留用户资料、会话与登录状态。
