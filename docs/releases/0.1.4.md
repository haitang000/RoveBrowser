# Rove 0.1.4

Rove 0.1.4 正式版改进扩展管理、设置与界面语言，并加入固定标签文件夹和 Agent 后台标签接口。

## 新增与改进

- **固定标签文件夹**支持创建文件夹、调整顺序和设置颜色；标签可拖入文件夹，也可通过右键菜单移动或移出。
- **扩展管理**可直接从 Chrome 网上应用店详情页安装扩展。扩展弹窗改为锚定工具栏的自适应浮窗，支持固定扩展按钮；弹窗中的链接会在浏览器标签中打开。
- **界面语言**可在设置中选择语言，新增繁体中文。
- **设置页面**重新整理布局，并将辅助功能设置独立为页面。
- **更新体验**显示下载进度，并在重启安装更新后通过 Windows 通知提示。
- **Agent 后台标签接口**提供独立于用户会话的后台标签管理和导航能力，默认关闭。

## 修复与细节调整

- 修复阅读模式关闭按钮未跟随阅读主题着色的问题。
- 新打开的链接标签会放在当前标签之后。
- 调整退出确认窗口布局，并在切回 Rove 时刷新窗口纹理。

## 下载与升级

- **安装版**：运行 `Rove-0.1.4-windows-x64-setup.exe`，可覆盖安装升级。
- **便携版**：解压 `Rove-0.1.4-windows-x64.zip` 后运行 `Rove.exe`。
- `SHA256SUMS.txt` 提供两个文件的 SHA-256 校验值。

支持 Windows 10/11 x64 和能够运行 x64 应用的 Windows ARM64，需要 Microsoft Edge WebView2 Evergreen Runtime。覆盖升级保留用户资料、会话与登录状态。
