# Rove 0.1.0

Rove 首个正式版本，汇总 0.1.0 系列预览版及后续改进，提供 Windows x64 安装程序与便携版。

## 主要功能

- **Space 与侧栏标签**：按工作区组织浏览会话，支持固定标签、最多 8 个跨工作区常用网站、拖动排序和悬停预览；自定义名称、表情图标、颜色、双色渐变与颗粒感。侧栏宽度可调整并保存，`Ctrl+Shift+F` 可切换完整展开。
- **浏览与分屏**：地址导航、历史、页面查找、站点缩放、静音与音频指示；两个真实网页并排浏览，Shift 点击链接可用 Peek 临时预览并转为标签。分屏入场与尺寸调整使用网页快照和 Space 渐变过渡，支持减少动态效果。
- **新标签页**：按时段问候、历史与收藏推荐，以及可添加、移除、排序和调宽的时钟、GitHub 贡献图、日历、便签 Widget；称呼、布局与便签随会话保存。
- **命令面板与设置**：搜索地址、标签和历史，执行浏览操作；配置搜索引擎、外观、下载目录、快捷键和浏览数据，搜索设置时高亮匹配项。
- **首次引导与导入**：引导选择工作区、搜索引擎和外观；支持导入 Edge、Chrome、Firefox、Brave、Vivaldi、Opera 的书签与历史，以及 CSV 密码。密码由 Windows DPAPI 加密，并需用户手动选择填充。
- **下载与会话恢复**：下载列表支持搜索、进度、暂停／继续、取消和历史；可打开 WebView2 的文件安全确认。SQLite 保存工作区、标签与历史，WebView2 保存站点登录状态；后台标签可自动休眠，并在重新打开时恢复。
- **Windows 集成**：可在系统设置中选择 Rove 处理 HTTP／HTTPS 链接，支持外部链接冷启动与单实例转交；安装和卸载保留用户资料。

## 相比 beta7 的改进

- 侧栏「新建」菜单整合 Space、分屏和标签页入口。Space 创建页支持名称验证、图标与主题预览；取消恢复原网页，创建后自动切换并保存。
- 重做新标签页与持久化 Widget，支持独立滚动；新增侧栏完整展开和标签拖动反馈。
- 分屏先移动原网页，再引入另一侧；优化窗口、侧栏和分屏缩放时的真实网页尺寸同步，修复透明快照残影并保持圆角轮廓清晰。
- 合并会话保存、后台写入 SQLite，并以增量消息同步界面状态，降低大量标签与连续操作的开销；优化首屏加载和网站图标处理。
- 修复可执行文件下载安全提示入口、标题栏最小化／最大化点击与刷新加载反馈；统一网页错误页，并高亮设置搜索结果。

## 下载与升级

- **安装版**：下载 `Rove-0.1.0-windows-x64-setup.exe` 并运行，默认安装到 `%LOCALAPPDATA%\Programs\Rove`，无需管理员权限。已有 WebView2 时可离线安装，缺少时调用微软引导程序安装运行时。
- **便携版**：下载 `Rove-0.1.0-windows-x64.zip`，解压后运行 `Rove.exe`；需预先安装 Microsoft Edge WebView2 Evergreen Runtime。

支持 Windows 10/11 x64，以及能够运行 x64 应用的 Windows ARM64。升级保留原有会话、书签与登录状态；沿用 EraBrowser 的用户资料目录。便携版默认也使用该目录。

## 已知限制

- 安装包尚未代码签名，暂不提供自动更新。
- 广告拦截后端、扩展、文件夹和站点权限管理界面尚未提供。
- 默认浏览器须在 Windows 设置中最终选择；仅处理 HTTP／HTTPS，不关联本地 HTML／PDF。
- 后台标签休眠不检测未提交的表单输入；可在设置中关闭。正在加载、播放声音和当前分屏的页面保持唤醒。
- 分屏比例暂不跨重启保存，网页快照可能显示最近捕获的画面；触控板手势及多屏混合 DPI 仍需更多硬件验证。
- GitHub 贡献图查询公开记录时需要联网，其余本地 Widget 可离线使用。
