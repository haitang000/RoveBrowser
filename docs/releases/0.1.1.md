# Rove 0.1.1

修复刷新网页时偶发未响应的问题，提供 Windows x64 安装程序与便携版。

## 修复内容

- 将刷新、加载完成和标题变化产生的浏览历史写入移至后台，避免数据库写入争用阻塞窗口，改善工具栏、Ctrl+R 和 F5 刷新时的响应。
- 保留实际访问时间，退出前完成待写入的历史；清除历史按顺序执行，避免旧任务在清除后重新写回记录。
- 新增真实 WebView2 刷新回归，覆盖数据库被占用、连续刷新、历史补写和清除顺序。

## 下载与升级

- **安装版**：下载 `Rove-0.1.1-windows-x64-setup.exe` 并运行，可覆盖安装升级。
- **便携版**：下载 `Rove-0.1.1-windows-x64.zip`，解压后运行 `Rove.exe`。
- `SHA256SUMS.txt` 提供两个文件的 SHA-256 校验值。

支持 Windows 10/11 x64，以及能够运行 x64 应用的 Windows ARM64；需要 Microsoft Edge WebView2 Evergreen Runtime。升级保留用户资料、会话与登录状态。

127 项 Rust 测试、105 项前端单元测试和真实 WebView2 刷新专项通过。部分既有综合回归仍有超时，具体范围及已知限制见[验证记录](https://github.com/haitang000/RoveBrowser/blob/v0.1.1/docs/VALIDATION.md)与[使用说明](https://github.com/haitang000/RoveBrowser/blob/v0.1.1/README.md)。
