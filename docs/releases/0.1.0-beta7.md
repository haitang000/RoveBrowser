# Rove 0.1.0-beta7

- 工作区外观支持自定义颜色、渐变、颗粒感与表情图标，清透背景加入轻量模糊；切换工作区时颜色、渐变和透明度平滑过渡。
- 侧栏支持拖动调整宽度，重启后保留；双击边缘可恢复默认宽度，并同步调整真实网页及分屏视口。
- 新增后台标签休眠以节省内存，再次打开时恢复；可在设置中关闭，当前页面、分屏、正在加载或播放声音的页面保持唤醒。
- 重做首次引导，整合工作区、搜索引擎和实际外观编辑器；下载浮窗改为支持搜索、文件类型图标和常用操作的气泡式列表。
- 标签页总览改为当前工作区主题色的半透明毛玻璃，支持自定义渐变和分屏网页快照模糊。
- 为标签及设置页面切换加入过渡，统一工作区图标搜索框样式。
- 修复渐变窗口外框白边、原生圆角、地址栏与缩放区域重叠，以及标题栏关闭按钮无法关闭窗口的问题；完善安装器构建兼容性。

Windows 10/11 x64。安装版升级保留原有会话、书签和登录状态；便携版解压后运行 Rove.exe。缺少 WebView2 时，安装版会使用微软引导程序安装运行时。

安装包尚未代码签名，暂不提供自动更新。后台标签休眠不检测尚未提交的表单输入；网页快照可能显示最近捕获的画面。
